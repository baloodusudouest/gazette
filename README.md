# Gazette

Un petit journal imprimé, « le monde le jour de votre naissance », pour les proches qui viennent dormir à la maison : un livret A5 de 4 pages, une feuille A4 pliée.

En conception : voir `docs/dossier.md`. Le prototype du premier livret est dans `tools/prototype/` (personne inventée).

Modèle commun des applis maison : [socle](https://github.com/baloodusudouest/socle).
